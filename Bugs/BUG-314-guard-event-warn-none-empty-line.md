## Analysis (reporter's hypothesis)
`guard.py:274`: `self.store.log_action(now, "guard", "guard", f"{a.kind}={a.value}", a.kind, cmd or "", dry_run, ok, a.reason)` formats `a.value=None` literally; `GuardAction.line()` (line 73) already handles `value is None`. The `reason` is empty in the stored detail for warn actions, so the dashboard line is empty after the colon.

## Suggested fix (optional)
Use `a.line()` for the log text and log warn actions with `a.reason`; skip `info` kinds.

## Info needed
None.

## Fix
Guard warnings without a command are no longer logged as action `warn=None` (they are in the warnings table, which the dashboard and postmortem show); other actions without a value are logged as the bare kind.
