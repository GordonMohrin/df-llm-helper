## Details
**FR-01 Order sanity check.** `dfllm cmd orders.check`: for each manager order, verify the workshop type exists
and is built, the material exists on the reachable walkable group, and a worker with the labor exists; report
orders that cannot run for N days and drop or pause them. Kernel economy checks every open order daily (built workshop, input on the citizens' walkable group, a worker with the labor; lua/dfllm/orderlib.lua) and raises ORDER_STUCK (B) after `orders.stuck_days` (3); `dfllm cmd inspect what=orders` lists the blockers. Dropping is FR-10's cancel rule; DF 53 orders have no pause. **Status: implemented in 8f14867 (offline, live-untested).**
**FR-02 Stuck-construction watch.** Per planned building: stage, days since placement, held item, worker. Alert
class A if a building is at stage 0 for more than 30 days or disappears.
**FR-03 Reachable-stock.** `inspect what=census` split by walkable group; mark items in other groups as
`unreachable`.
**FR-04 Burial/ghost monitor.** Goals-style thresholds in the kernel: loose corpses > 20 or ghosts > 5 raises a
class A event and an automatic coffin/tomb project. **Status: implemented in e2bffc7 (offline, live-untested).** GHOSTS (A) comes earlier than asked: at the first citizen ghost or a citizen body unburied longer than 3 days; tomb projects stay PROJECT_REQUEST tombs (follow places them).
**FR-05 Job-pickup diagnostic.** For one job id: labor needed, units who could take it, why each does not
(labor off, no path, burrow, busy). Read only.
**FR-06 suspendmanager verb.** `dfllm cmd suspendmanager preventblocking=false` through the allowlist, and a
baseline option that stops forcing it on.
**FR-07 Hostile explainer.** `dfllm cmd inspect what=threat` listing the units counted as hostile, with race, z,
walkable group and why.
**FR-08 Embark waiver.** Allow `--accept <criterion>` for failed (not only unshown) criteria with a logged **Status: implemented in 847bc11 (offline, live-untested).**
reason, and a "relax old_sites" rule when the old fort is ruined.
**FR-09 Prepare carefully.** Drive the skill rows (known blocker: clicks ignored, see embark README).
**FR-10 Pruner.** Kernel drops manager orders that cancelled more than N times for "Needs ..." reasons. Economy counts "Needs ..." cancels per order over 7 days and removes the order at `orders.needs_drop` (10) through `act.order_remove` (ORDER_STUCK dropped=1); brewing, meals, barrels and fish preparation are never removed; an own dfllm order waits `orders.backoff_days`. **Status: implemented in 8f14867 (offline, live-untested).**
**FR-11 Trend dashboard.** Season-by-season table in `dfllm brief`.
**FR-12 Rebuild helper.** Keep a manifest of placed buildings; `bp.restore` re-places the missing ones.

**FR-13 Plan check without manifest.** Accept room templates after a fortcore stage in the same plan (dry-run the manifest), or have `plan propose` emit a first plan with fortcore only and a note to re-propose after placement.

**FR-14 Aquifer pass-through.** New template `aqshaft`: a sealed 1-wide shaft through damp layers (dig down, smooth walls at once, optional channel chamber 10 levels below). `fortcore` should accept `aquifer=pass|above|drain` and resume after the shaft is sealed.
**FR-15 Duplicate guard.** `bp.place` refuses a template that the active plan already places on the same site, and `plan apply` skips a build entry whose project already exists.

**FR-16 Work detail + unsuspend verbs.** `economy` assigns Plant gatherers, Fisherdwarves and Hunters when food < 20 days and idle > 30 %; add a verb `jobs.release` for suspended ConstructBuilding jobs with a reason report, and stop baseline from forcing suspendmanager on. Economy resumes suspended ConstructBuilding jobs nobody keeps suspended (buildingplan's planned ones and suspendmanager's kept ones are reported by reason, JOBS_SUSPENDED and `inspect what=workload`); verb `jobs.release {all?, preventblocking?}`; preventblocking is a persisted fort decision (DECISION_NEEDED preventblocking after 3 days), baseline never sets it. Gatherers and planters join in a starvation (FR-25); hunters and fishers keep the famine rules. **Status: implemented in 8f14867 (offline, live-untested).**

**FR-17 Farm season slots.** The economy module should set a crop for all four seasons per plot (underground plots grow all year), preferring a crop already in stock as seed; add a census line 'farm plots with empty slots'. Every empty season slot of every built plot gets a crop that grows in that season and place (underground crops all year), a crop with usable seeds first (`act.farm_crop`); census `farm_plots`/`farm_empty`. **Status: implemented in 8f14867 (offline, live-untested).**

**FR-18 Caravan offer.** `inspect what=trade` lists the merchants' goods (types, counts, prices) once the depot is open, `trade.want` can then name items that exist; report unmet wants per caravan. `dfllm cmd inspect what=trade` lists the merchant goods in the depot once a caravan stands there (the depot's goods list: type, material, units, value and the want token that names them), plus wants, sell list and the ledger (FR-32). **Status: implemented in 9839c64 (offline, live-untested).**

**FR-22 Reachability audit.** `inspect what=reach`: walkable groups of citizens, food, seeds, farm plots, wells, depot and exit; flags any item class whose group differs from the main citizen group, and any STAIR_UP/STAIR_DOWN without a counterpart. Run it before and after any construction that could close a path (walls, doors, bridges). Run 9 lost 43 of 56 citizens to a self-built wall ring plus an entrance stair without a counterpart (see memory feedback_df_abriegelung_connectivity). **Status: implemented in 0aaa672 + 4ae37ca (offline, live-untested).**

**FR-23 Forbidden seed bags.** The census should report seeds that are unusable (forbidden item or forbidden container) separately from usable seeds; `economy` unforbids seed containers. Census `seeds_ok` / `seeds_forb` (a forbidden item or container, any item type); economy unforbids the seeds and their bags on revealed, reachable tiles in PEACE/RECOVERY. **Status: implemented in 8f14867 (offline, live-untested).**

**FR-24 Lever vs bridge truth.** `inspect what=defense` prints each bridge's `gate_flags.raised` and the walkable result through it, next to the lever's linked state; the lever list alone mislead us. **Status: implemented in 0aaa672 (offline, live-untested).**

**FR-25 Starvation handler.** At food_days 0 and hungry citizens, mark every reachable visible edible plant for gathering (`dfhack.designations.markPlant`), set Gatherer and Planter details, unforbid food, and report who cannot reach food.
