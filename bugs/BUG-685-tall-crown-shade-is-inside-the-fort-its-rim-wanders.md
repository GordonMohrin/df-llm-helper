# BUG-685 The shade of a tall tree counts as the fort's inside: its rim is a new way in every season
Status: fixed (offline, live-untested)
Severity: high
Found: 2026-11-10, Run 16a i1 Basementflew (z131: 32,121 / 117,109 / 57,114 and more, FR-BUGS 'wechselnde Oberflaechen-floor-Oeffnungen, neue Kacheln jedes Quartal') and Run 16d i4 Trumpetrealms y450-y454 (10+ seals in 5 years: 93,90 / 10,175 / 8,177 / 21,174 / 60,55 / 72,78 / 108,44 / 93,99 / 91,76 / 99,78; events.jsonl SIEGE_UNREADY `ents` '77,73,141 floor', '109,109,141 pebbles', '64,147,141 floor', '100,89,141 floor', '127,113,141 floor', '68,141,141 floor' ... all on the surface level z141, 20-60 tiles from the fort, never the same tile twice)
Module: `lua/dfllm/seal.lua` (`open_sky`, `door_outside`)

## Actual
- Every game season `status` named 1-3 new 'floor' / 'pebbles' ways in without a door on the surface far from the fort; each one had to be closed by hand (`seal at=last`), `plan check` refused P5 while the perimeter was open and `open_perimeter` held the pop ceiling for 2-4 weeks each time. The tiles never repeat, the readiness check dropped some of them as 'younger than 2400 ticks' (BUG-600), and BUG-566's sapling / shrub rule did not touch them (the kind is floor / pebbles, not a plant).
- 'Inside' of the entrance check = every tile of the citizens' walk group that is not open sky. A surface tile under a tree has `designation.outside` false although only branches roof it (BUG-503), so `open_sky` looks up the column. BUG-566 read four levels and returned 'roof' when the four levels were all empty air.

## Root cause
`seal.lua` `open_sky`: `TREE_UP = 4`, and the loop ended with `return false` (roofed). A grown tree has its trunk six to ten levels high and its branches from five to eight levels above the ground; the floor beside the trunk has only empty air for the first four levels, so the old loop ran out and called the shaded patch under the crown inside. Wherever such a patch touches the citizens' group (a surface corridor, a stair that comes up in a wood) the whole patch is 'inside the fort' and its RIM is a list of new ways in. The rim moves whenever a crown does: a sapling grows into a tree (new crown), a tree dies or is felled (crown gone, the neighbour's crown now rims the hole), the seasons shift the stand. That is the 'wandering perimeter' of both forts. (Offline reading of the code and the logs: the tile kinds (floor / pebbles on z141), the distances from the fort and the seasonal rhythm all fit; the tree heights themselves are not in any log. `stats.crown_hi` counts the tiles only the longer read decided, so the live check can show it.)
- A second place read `designation.outside` alone: `door_outside` (the lockdown's 'citizens outside this door'), so a woodcutter in the shade of a tall crown counted as inside and the door was forbidden with him still outside (locked out). It now uses `open_sky`, like the entrance check.

### Correction after the snapshots (verifier)
The four-level read alone was not what the logs show. The snapshots in `snap/` hold the tiles above the rim: i4 Trumpetrealms `s184011239-109.json` column z140..z145 at the sealed rim tiles 91,76 / 99,78 / 93,90 / 72,78 reads `?+T.` (door at z141, trunk at z142), 60,55 `?+TT`, 108,44 `?.T.`; unsealed ways in of the same era have a trunk above too (floor 101,103,141 `#.TT`, shrub 80,85,141 `?.T.`); i1 Basementflew `s196380449-123.json` 32,121 / 117,109 / 57,114 at z131 each `#+T` (trunk at z132). `T` = a WALL tile of TREE / ROOT material (snapshot.lua tt_info). 8 of 8 sealed and 2 of 2 listed rim tiles have a trunk directly above, none a column of four empty levels. `open_sky` treated that trunk as a roof (`s.shape ~= 'EMPTY'`; TREE_ROOF held only BRANCH / TRUNK_BRANCH / TWIG), so a floor tile under a leaning or growing trunk was 'inside' while its neighbours (all air) were open sky: the rim sat on the trunk tile and moved with every tree that grew, fell or was felled. The 12-level read stays (crowns above four levels are real) but is not the main cause.

## Fix
- `open_sky` (seal.lua ~275-300): a WALL tile of TREE or ROOT material in the column (a trunk) is a tree part like a branch: open sky, on the surface (`des.subterranean` false) only; a built wall / floor / construction is still a roof, as is a built floor anywhere above a trunk's level.
- `open_sky`: the column is read up to `TREE_UP = 12` levels; a tree part decides open sky, a built floor / wall / anything not empty is a roof, and a column of empty air for all twelve levels has no roof (open sky). `mem.stats.crown_hi` counts the tiles only the longer read decided (inspect reach `runs.crown_hi`). A nil tile (off the map) stays 'roof' as before.
- `door_outside`: `out` = `open_sky(...)` instead of `designation.outside`.
- The kernel's job scan / burrow paint (`job_scan`, `paint`) still read `designation.outside` alone (the interior burrows are not part of this change).
