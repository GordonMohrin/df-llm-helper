# Features

Feature requests for the df-llm-helper cloud session, from the local orchestrator (the one who plays the game).
Bugs go to `Bugs/`, wishes for new behaviour go here.

## File naming
`Features/FEATURE-<NNN>-<short-slug>.md`, status in the header: `proposed` / `accepted` / `implemented in <commit>` / `declined`.

## Required content
Problem (with a real incident), proposed command or behaviour, data it needs from the game, safety / fair-play notes,
acceptance criteria that the cloud session can test with a recorded fixture (it has no access to the live game),
and "Info needed" if the cloud session needs a decision or a recording from the player.
